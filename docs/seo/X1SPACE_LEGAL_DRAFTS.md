# X1 Space Explorer legal drafts

Owner review required. These drafts are repository documentation for review and have no application routes.

## Draft Privacy Policy

ARKBS Labs develops and operates X1 Space Explorer. Send privacy questions to support@arkbslabs.com.

When you use the explorer, it requests blockchain records from public X1 RPC services and uses the XDEX API for supported liquidity-pool views. Depending on the feature, requests can include an address, transaction signature, validator vote account, slot, or token mint you look up. These identifiers concern public blockchain records. A lookup does not place a new record on the blockchain.

The application uses browser storage for features such as watchlists, portfolio entries, dashboard preferences, and cached explorer results. If you use a Base44 authentication flow, the application uses Base44 to check account access and can store session-related information in the browser. Clearing website data from your browser can remove locally stored settings and may affect sign-in.

If you email support, your message can include your email address, the affected page, and any information you choose to provide. Avoid sending passwords, private keys, or seed phrases.

## Draft Terms of Service

X1 Space Explorer is an independent explorer for viewing and interpreting records on X1 mainnet. Use public identifiers when searching. Do not send recovery phrases, private keys, or passwords to support.

Blockchain and market data can be delayed or incomplete because of upstream availability, indexing, or network conditions. Validate important records independently using the chain or a trusted source. Validator and token metadata can be self-published. A displayed name, icon, listing, or price does not establish authenticity or endorsement. Staking estimates and pool-derived prices are informational.

For questions about the explorer or to report an issue, email support@arkbslabs.com.
